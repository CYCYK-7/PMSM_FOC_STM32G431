# STM32G431 PMSM Hall-FOC 实机开发阶段笔记

**记录日期：** 2026-10-15

**阶段范围：** Hall 电角度偏置标定 → d/q 电流 PI 实机闭环 → 3 秒运行验证 → Hall 速度外环 + 电流内环双闭环

**阶段结论：** 已在实际电机上完成 100 rpm、150 rpm 两种速度指令下的双闭环基本功能验证，可以进入运行中动态调速阶段。但当前结果不代表电流环与速度环已经完成最优整定。

## 1. 本阶段开始前的基础

此前已经完成：

- STM32G431 三相互补 PWM 输出及 SVPWM 算法。
- ADC 同步采样、OPAMP 电流测量及零点校准。
- Hall 六状态检测、扇区映射、机械转速计算。
- 固定电压矢量对齐及低速开环旋转。
- 1 V 电压、15 rpm 开环旋转实机验证。
- 软件故障检测、PWM 关闭、SW3 长按启动与状态机。

本阶段的目标不再是让电机简单旋转，而是逐步建立可运行的 Hall-FOC 电流、速度闭环控制系统。

电机经手动检查，每机械转一圈具有约 12 次 Hall 状态变化，因此当前使用 **2 对极**。

## 2. Hall Offset 标定

### 2.1 标定目的

Hall 传感器获得的是离散转子位置信息，其角度零点不一定与 FOC 中使用的转子磁链方向重合。

因此，在 Park 和 InvPark 变换前，需要进行角度偏置补偿：

```
theta_e_foc = WrapAngle0To2Pi(hall_theta_rel + hall_offset_test_rad);
```

### 2.2 实际标定方法

通过低速旋转电压矢量，分别完成 CW 和 CCW 两个方向的 Hall 边沿采集，再进行角度偏置估计。

进行了两次独立标定：

| 标定次数 | Hall Offset    |
| -------- | -------------- |
| 第一次   | 3.76684737 rad |
| 第二次   | 3.76550007 rad |
| 差值     | 约 0.00135 rad |

最终采用：

```
hall_offset_test_rad = 3.76550007f
```

对应约 **215.75° 电角度**。

### 2.3 认识与局限

两次结果接近说明标定方法具有较好的重复性，但不能证明绝对角度精度达到 0.077°。

标定时 CW 与 CCW 的角度估计还存在明显差异，因此后续如果需要精确转矩控制，仍需进一步验证绝对角度误差。

**本阶段先将该偏置作为可用的 Hall-FOC 控制基线。**

## 3. 第一次实现真正的 d/q 电流 PI 闭环

### 3.1 控制流程

成功将 Hall 校正角度接入实际电流控制算法：

1. ADC 同步采集相电流；
2. Clarke 变换，得到 αβ 电流；
3. Hall 估算电角度及 Park 变换；
4. d/q 电流 PI 计算电压指令；
5. 电压矢量幅值限幅；
6. InvPark、SVPWM 更新 TIM1；
7. 超时或故障时关闭 PWM，返回 READY。

电流控制周期：

```
Ts = 50 μs
```

即 **20 kHz**。

初始给定：

- `Id_ref = 0 A`
- `Iq_ref = 0.08 A`
- `Kp = 2`
- `Ki = 40`

### 3.2 初步实机测试

首先采用 1.0 V 电压上限，随后调整为 1.5 V。

| 指标           | 1.0 V 测试 | 1.5 V 测试 |
| -------------- | ---------- | ---------- |
| 目标 Iq        | 0.08 A     | 0.08 A     |
| 后段平均 Iq    | 0.02857 A  | 0.03319 A  |
| 电压近限幅比例 | 65.93%     | 34.40%     |
| 电机表现       | 能启动加速 | 加速更明显 |

说明电流 PI 已参与实际控制，但 1.0 V 电压限幅对电流跟踪影响明显。

不过，电机转速在两次实验中并不相同，因此不能仅凭平均 Iq 的变化确定全部原因。

### 3.3 PI 积分增益对比

进一步缩短测试窗口，重点观察启动早期电流跟踪。

| 指标         | Ki=40     | Ki=80     |
| ------------ | --------- | --------- |
| 平均 Iq      | 0.04631 A | 0.03631 A |
| 平均 Iq 误差 | 0.03369 A | 0.04369 A |

增加 Ki 后，并未改善跟踪，反而导致平均误差增大。

随后检查 `pi_controller.c/.h`，确认误差、比例、离散积分、单轴输出限幅以及条件积分抗饱和的基本实现逻辑没有明显错误。

**阶段决定：恢复 Ki=40，停止无目标地提高 PI 增益。**

## 4. 电流动态数据采集与 Hall 角度估算分析

### 4.1 为什么增加数据记录

最初只能在测试结束后读取平均电流和峰值，无法判断具体动态过程。

因此新增 RAM 数据采集功能：

- 在 ADC 中断中累积采样数据；
- 按固定时间窗口记录平均值；
- 同时保留 Iq 的最小值和最大值；
- 运行结束、PWM 关闭后，再通过 USART3 输出 CSV；
- 避免在 20 kHz 中断中执行耗时的串口输出。

主要记录变量包括：

`iq_ref`、`id_avg`、`iq_avg`、`iq_min`、`iq_max`、`vd_avg`、`vq_avg`、`iq_integ`、`hall_rpm`、`theta_rad`。

### 4.2 Hall 角度问题

观察动态数据后发现，电机加速时 Hall 角度估计可能出现较大的边沿修正。

原因之一是原算法使用上一 Hall 扇区的平均速度对当前位置进行恒速预测，而实际转速正在变化。

随后尝试利用相邻 Hall 扇区通过时间估计加速度，对电角度进行预测补偿。

### 4.3 A/B 测试结论

新算法在部分短时测试中表现有所改善，但不同测试的启动和加速过程并不一致，而且有效 Hall 边沿样本较少。

加速度补偿还存在预测角度提前抵达扇区边界的情况。

因此，暂时没有足够证据证明其优于旧算法。

最终保持：

```
HALL_ANGLE_PREDICT_ENABLE = 0U
```

即继续使用旧恒速插值算法。

**经验：不能因为一次实验指标变好，就认定某个算法改动有效。比较算法前应尽量保证工况一致。**

## 5. 延长电流闭环测试至 3 秒

### 5.1 修改动机

此前测试时间只有 650 ms，其中 Iq 保持恒定给定的时间仅约 250 ms。

此时电机仍处于启动、加速阶段，不能有效反映稳定运行情况。

因此决定：

- 总运行时间：3 s；
- Iq 目标：0.08 A；
- 电流 PI：Kp=2，Ki=40；
- 电压上限：1.5 V；
- CSV 采样间隔：50 ms；
- 统计最后 1 秒数据。

### 5.2 实机结果

| 最后 1 秒统计指标 | 实测结果           |
| ----------------- | ------------------ |
| 平均 Hall 转速    | 254.22 rpm         |
| Hall 转速范围     | 242.60～267.52 rpm |
| 目标 Iq           | 0.0800 A           |
| 平均实际 Iq       | 0.03301 A          |
| 平均 Id           | -0.00014 A         |
| 平均 Vq           | 1.4960 V           |
| 电压限幅          | 1.5 V              |

### 5.3 结论

电机运行约 1 秒后逐渐进入相对稳定的工作区间，最后两秒的平均转速和电流变化已经比较小。

但是实际 Iq 仍明显低于 0.08 A。

主要原因是：**电机加速到约 254 rpm 后，q 轴输出电压已基本达到人为设置的 1.5 V 上限。**

电流 PI 虽然仍在调节，但受限于电压裕量，无法完全消除电流误差。

这说明以前的短时测试确实存在暂态干扰，而延长测试时间也帮助我们明确了电压限幅下的稳定工作点。

**这是本阶段非常重要的实验认识。**

## 6. 实现 Hall-FOC 速度外环 + 电流内环

### 6.1 双闭环结构

速度外环负责根据转速误差产生 Iq 给定，电流内环负责根据 Id/Iq 给定控制实际逆变器输出。

控制链路：

**速度给定 → 速度 PI → Iq_ref → d/q 电流 PI → InvPark → SVPWM → PMSM**

Hall 传感器为速度 PI 提供机械转速反馈，为电流 PI 的 Park/InvPark 变换提供电角度。

### 6.2 核心参数

| 参数            | 当前设置         |
| --------------- | ---------------- |
| 电流环周期      | 50 μs            |
| 速度环周期      | 10 ms            |
| 电流 PI Kp      | 2.0              |
| 电流 PI Ki      | 40.0             |
| 速度 PI Kp      | 0.0008 A/rpm     |
| 速度 PI Ki      | 0.0006 A/(rpm·s) |
| Iq 给定上限     | 0.08 A           |
| 电压矢量上限    | 1.5 V            |
| 总运行时间      | 3 s              |
| 速度指令斜坡    | 1 s              |
| 数据记录间隔    | 50 ms            |
| Hall 加速度补偿 | 关闭             |

这版速度 PI 只允许输出 `0～0.08 A` 的正向 q 轴电流，因此当前只验证正向调速，并未实现反转或负转矩主动制动。

为避免使用残留 Hall 转速，新程序要求本次 RUN 中至少出现两次有效 Hall 边沿，才采信速度反馈，并进行适度低通滤波。

### 6.3 100 rpm 实机验证

电机实际表现：

**完成对齐后缓慢启动，逐渐加速，随后在较低转速附近稳定运行。**

最后 1 秒实测：

| 指标             | 结果          |
| ---------------- | ------------- |
| 目标速度         | 100 rpm       |
| 平均速度反馈     | **95.91 rpm** |
| 平均速度偏差     | -4.09 rpm     |
| 平均相对误差     | -4.09%        |
| 平均绝对速度误差 | 7.62 rpm      |
| 平均 Iq_ref      | 0.03003 A     |
| 平均实际 Iq      | 0.02984 A     |
| 平均 Vq          | 0.68908 V     |

串口汇总：

```
SPEED_SUMMARY,ref=100.0,avg=95.94,peak=113.99,iq_ref=0.0342,valid_ticks=100,updates=299,hall_edges=40,fault=0
```

**结论：100 rpm 速度双闭环基本功能验证通过。**

电机不再维持固定的 0.08 A 给定并不断加速，而是由速度 PI 按需减小 q 轴电流，在约 100 rpm 附近运行。

### 6.4 150 rpm 实机验证

保持其他参数不变，仅将目标速度从 100 rpm 调整至 150 rpm。

最后 1 秒实测：

| 指标             | 结果           |
| ---------------- | -------------- |
| 目标速度         | 150 rpm        |
| 平均速度反馈     | **146.49 rpm** |
| 平均速度偏差     | -3.51 rpm      |
| 平均相对误差     | -2.34%         |
| 平均绝对速度误差 | 6.64 rpm       |
| 平均 Iq_ref      | 0.03211 A      |
| 平均实际 Iq      | 0.03064 A      |
| 平均 Vq          | 0.94737 V      |

串口汇总：

```
SPEED_SUMMARY,ref=150.0,avg=147.05,peak=162.73,iq_ref=0.0332,valid_ticks=100,updates=299,hall_edges=63,fault=0
```

**结论：150 rpm 速度双闭环基本功能验证通过。**

当目标提高至 150 rpm，实际速度也相应提高，而不是仅在原先约 100 rpm 的位置维持。

| 指标              | 固定电流模式   | 100 rpm 速度模式 | 150 rpm 速度模式 |
| ----------------- | -------------- | ---------------- | ---------------- |
| 控制目标          | Iq=0.08 A      | 100 rpm          | 150 rpm          |
| 最后 1 秒平均速度 | 254.22 rpm     | 95.91 rpm        | 146.49 rpm       |
| 平均实际 Iq       | 0.03301 A      | 0.02984 A        | 0.03064 A        |
| 平均 Vq           | 1.496 V        | 0.689 V          | 0.947 V          |
| 电压限幅          | 1.5 V          | 1.5 V            | 1.5 V            |
| 结果              | 电压受限后趋稳 | 基本速度跟踪     | 基本速度跟踪     |

这些数据说明，速度外环已经能够根据转速目标调节 q 轴电流需求，并改变电机实际运行速度。

但仍存在一定 Hall 速度反馈波动、电流瞬时采样波动和 PI 动态误差，尚不能称为高精度或高性能控制系统。

## 8. 本阶段最重要的工程认识

1. **功能实现与性能整定是两个不同的阶段。** 电机能够完成闭环运行，不代表电流和速度控制已经达到最优性能。
2. **必须区分启动暂态与稳定运行。** 650 ms 实验中包含大量启动过程，不能直接当作稳态性能评价。
3. **电压限幅是理解电流环结果的关键因素。** 3 秒固定电流实验中，电机达到约 254 rpm，而 q 轴电压几乎一直处于 1.5 V 上限附近。
4. **Hall 角度算法不是越复杂越好。** 加速度补偿需要充分的实机证据才能说明优于恒速插值，不能只根据个别实验选择算法。
5. **闭环控制应按清楚的层级组织。** 速度 PI 产生 Iq 给定；电流 PI 负责跟踪；SVPWM 执行电压输出。不同控制环应采用合理的更新周期。
6. **实验诊断应服务于实际目标。** 通过 RAM 缓冲与 CSV 采集，可以分析运行全过程，而不是只比较几个单独的 Debugger 变量。
7. **优先推进完整系统，再针对明确问题优化。** 不能在尚未证明的局部问题上反复试错，影响整个电控项目的开发进度。

**阶段总结：**

本阶段成功将 STM32G431 PMSM 控制程序从 Hall Offset 标定和 d/q 电流 PI 初步闭环，推进至完整的 Hall-FOC 速度外环 + 电流内环结构。
